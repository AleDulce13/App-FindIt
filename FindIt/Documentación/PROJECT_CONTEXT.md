
# PROJECT_CONTEXT.md

# 1. Información general

Nombre del proyecto: FindIt.

Descripción:
Aplicación móvil que permitirá a los estudiantes publicar
objetos encontrados dentro de las instalaciones de su
universidad para facilitar que sus propietarios puedan
localizarlos y recuperarlos.

# 2. Problemática

En las universidades es común que los estudiantes
pierdan objetos personales, como identificaciones,
mochilas, llaves, celulares y otros artículos.

Actualmente, la recuperación de estos objetos depende
de publicaciones informales en grupos de redes sociales
o avisos entre estudiantes.

# 3. Objetivo general

Desarrollar una aplicación móvil para Android que
facilite la publicación, búsqueda y recuperación
de objetos perdidos dentro de las universidades.

# 4. Usuarios

- Estudiantes.
- Administradores responsables de la comunidad de cada universidad.

# 5. Funcionalidades principales

- Registro e inicio de sesión.
- Identificación de universidad.
- Publicación de objetos encontrados con fotografías.
- Consulta de publicaciones.
- Búsqueda y filtrado de objetos.
- Comentarios en publicaciones.
- Comunidades independientes por universidad.

# 6. Tecnologías aprobadas

- Plataforma: Android.
- Framework: .NET MAUI.
- Lenguaje: C#.
- IDE: Visual Studio 2022.

# 7. Reglas de negocio

- Cada usuario pertenece a una universidad.
- Los usuarios solo podrán consultar las publicaciones
  de su propia comunidad universitaria.
- Las publicaciones deben incluir información
  que describa el objeto.
- Los comentarios solo estarán en la publicación.

# 8. Restricciones

- La primera versión será exclusivamente para Android.
- El desarrollo se realizará con .NET MAUI.
- Las funcionalidades se implementarán por etapas.

# 9. Decisiones aprobadas

- Desarrollo de una aplicación móvil.
- Compatibilidad exclusiva con Android para el MVP.
- Uso de .NET MAUI y C#.
- Organización de usuarios por universidad.

# 10. Decisiones pendientes

- Definir el servicio de almacenamiento de imágenes.
- Definir el proveedor de autenticación.
- Definir el mecanismo de notificaciones.
