
# IMPLEMENTATION_PLAN.md

# 1. Objetivo del plan

Establecer las etapas necesarias para desarrollar
la aplicación móvil de objetos perdidos universitarios (FindIt).

# 2. Etapas de implementación

## Etapa 1. Configuración inicial

- Crear el proyecto .NET MAUI.
- Configurar Visual Studio 2022.
- Organizar las carpetas y archivos.
- Configurar el entorno Android.

## Etapa 2. Diseño de interfaces

- Diseñar la pantalla de inicio.
- Diseñar el registro.
- Diseñar el inicio de sesión.
- Diseñar el menu.
- Diseñar el listado de publicaciones.
- Diseñar el formulario para publicar objetos.

## Etapa 3. Autenticación y usuarios

- Implementar el registro.
- Implementar el inicio de sesión.
- Asociar usuarios con universidades.
- Validar el acceso a las comunidades.

## Etapa 4. Gestión de objetos

- Publicar objetos encontrados.
- Agregar fotografías.
- Consultar publicaciones.
- Buscar y filtrar objetos.
- Consultar detalles de publicaciones.

## Etapa 5. Interacción

- Implementar comentarios.
- Permitir la interacción entre estudiantes.
- Implementar las funciones de recuperación
  de objetos.

## Etapa 6. Pruebas

- Realizar pruebas unitarias.
- Realizar pruebas de integración.
- Realizar pruebas funcionales.
- Realizar pruebas de usabilidad.
- Corregir errores encontrados.

## Etapa 7. Entrega

- Verificar el funcionamiento general.
- Generar la versión de prueba para Android.
- Documentar los resultados.

# 3. Criterios generales de finalización

- Las funcionalidades principales funcionan.
- Los usuarios pueden acceder a su comunidad.
- Las publicaciones pueden consultarse.
- Los errores críticos están corregidos.
- Las pruebas definidas se han ejecutado.

# 4. Estado del proyecto

En desarrollo.
